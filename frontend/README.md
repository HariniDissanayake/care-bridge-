# CareBridge Frontend

Single-page React + Vite + Tailwind CSS implementation based on the supplied CareBridge UI reference.

## Technology
- React
- Vite
- Tailwind CSS
- Lucide React icons

## Run

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, normally:

http://localhost:5173

## Notes
This is frontend-only. The mood buttons, quick replies, text input and send button have small local interactions so the page can be tested without a backend.
